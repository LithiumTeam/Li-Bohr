# Li-Bohr

وب‌سایت ایستاتیک (بدون بک‌اند) برای ساخت مدل اتمی بور: کاربر تعداد پروتون، نوترون و الکترون را وارد می‌کند و یک تصویر PNG (۹۰۰×۹۰۰) از آن اتم ساخته و قابل دانلود است.

## امکانات

- ورودی پروتون / نوترون / الکترون (عدد‌های مثبت یا صفر؛ اتم خنثی لازم نیست)
- شناسایی عنصر از روی تعداد پروتون (۱ تا ۱۱۸) و نمایش نام فارسی و انگلیسی اتم روی تصویر
- پراکنش الکترون‌ها در لایه‌ها بر اساس ظرفیت‌های ۲، ۸، ۱۸، ۳۲، ۵۰، ۷۲
- تم روشن/تیره با ذخیره در `localStorage`؛ تصویر اتم با پالت رنگی هر تم رندر می‌شود
- دانلود تصویر با یک کلیک (بدون ارسال به سرور)

## اجرا

هیچ نصبی لازم نیست: فایل `index.html` را مستقیم در مرورگر باز کنید، یا پوشه را با هر سرور ایستاتیک سرو کنید.

## ساختار

```
index.html               تنها فایل HTML
css/style.css            تمام استایل‌ها (CSS دستی، بدون بوت‌استرپ)
css/bootstrap-icons.min.css  فقط آیکون‌ها
js/main.js               فرم، رندر canvas و دانلود
font/                    Vazirmatn Bold (فارسی) + JetBrains Mono Bold (عنوان و اسم انگلیسی اتم)
images/icon.png          آیکون سایت و لوگوی هدر
```
